Name:
Movie Collection App | Personal Portfolio Project

App Description:
Blazor web application using entity framework, Claude Haiku, Docker, Neon, and Render. 

Key Features:
- Ability to search for movies via the TMDB API.
- View Favorite Movies saved
- Add/Remove favorites functionality
- Filtering Favorite Movies
- Movie Assistant using Claude Haiku
- Pagination
- Toast messaging

Made with:
- Blazor
- Bootstrap
- Entity Framework
- Docker (Deploying)
- Neon (PostgresSQL)
- Render (Hosting)
- TMDB Movie API for searching
- Claude AI for Movie Assistant

Tech stack:
- Visual Studio 2026
- Entity Framework Core 10.0.12
- TMDbLib 3.0.0
- Npgsql 10.0.3
- Bootstrap 5.3.3
- Claude Haiku 4.5

About
Movie Collection is a personal portfolio project developed to demonstrate full-stack web development skills using C#, ASP.NET Core, Blazor, Entity Framework Core, and PostgreSQL.
The application allows users to search for movies, view movie information, and manage a collection of their favorite films.
Movie information and associated images are provided by The Movie Database (TMDB).
This application is intended for educational and portfolio demonstration purposes only. It is not a commercial product and is not affiliated with or endorsed by any movie studios or distributors.
